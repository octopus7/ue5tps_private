## 커버 디버그 좌우 표기 주의
- 커버 라인은 로컬 +X 방향으로 T 값이 증가하며, 라인 노멀 방향과 플레이어 진입 방향에 따라 화면상 좌/우가 뒤바뀌어 보일 수 있습니다.
- 디버그 스피어(노란색)는 실제 커버 라인상의 T 위치를 그대로 표시합니다.
- 흰색 텍스트(Left/Right, T 값)는 컨트롤러에서 계산한 진입 기준 좌/우로 보정되어 표기되므로, 물리적인 라인 좌표와 다를 수 있음을 염두에 두세요.
